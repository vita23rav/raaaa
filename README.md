
# Character Manager — TP3 (Java Visual SIH-6406)

## Deskripsi
Character Manager adalah aplikasi berbasis Java yang digunakan untuk membuat dan menampilkan karakter dengan tipe, level, HP, dan attack power. Program ini menerapkan konsep Object-Oriented Programming (OOP), termasuk encapsulation, constructor, enum, serta validasi data. Pada pengembangan fitur, program dilengkapi atribut mana dan method isAlive() untuk memeriksa apakah karakter masih hidup.
